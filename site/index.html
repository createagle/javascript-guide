JavaScript 零基础入门

8 章带你从第一行 console.log 走到一个能在浏览器里运行的待办清单应用。不需要安装任何软件，一个现代浏览器就够了。

课程文字讲解在 Claude Docs 中，这个网站提供每章配套的示例代码。每个示例都能直接修改并运行，改坏了点「重置」即可恢复。

课程目录

  1. 认识 JavaScript 与开发环境约 1 小时
  2. 变量与数据类型编写中
  3. 运算符与流程控制编写中
  4. 函数与作用域编写中
  5. 对象与数组编写中
  6. DOM 与事件编写中
  7. 异步编程编写中
  8. 综合项目：待办清单编写中
