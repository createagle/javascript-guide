3. 在网页里使用 JavaScript

真实项目里，JavaScript 写在网页中，用 <script> 标签引入，有内联和外部文件两种写法。下面是一个完整的例子：

index.html

<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8" />
  <title>第一个页面</title>
  <script src="main.js" defer></script>
</head>
<body>
  <h1>你好</h1>

  <script>
    console.log("来自内联脚本");
  </script>
</body>
</html>

main.js

console.log("来自 main.js");

在新标签页打开这个示例页面，按 F12 打开开发者工具，切到 Console，会看到两行输出：先是内联脚本的，后是 main.js 的，因为带 defer 的脚本要等页面解析完才执行。

浏览器从上到下解析 HTML，脚本执行时，它下面的元素还没创建出来。所以要么把 <script> 放在 </body> 之前，要么放在 <head> 里并加上 defer。本课程默认采用后一种。

6. 课后练习

三道题由易到难，建议都亲手敲一遍，卡住了再看参考答案。

练习一：打印你的名字

用 console.log 打印 你好，我是 加上你的名字。

参考答案 
console.log("你好，我是 Ann");

练习二：时间换算

算出 3 小时 20 分钟等于多少分钟，用 console.log 打印出来。

参考答案 
console.log(3 * 60 + 20); // 200

练习三：三种输出与一次故意的错误

在 main.js 里用 log、warn、error 各打印一句话，确认三种颜色不同；再故意把 console 拼成 consle，说出报的是哪种错误。先在下面的编辑器里试，再照第 3 节的做法，在自己电脑上新建 index.html 和 main.js 验证一遍。

参考答案 
console.log("这是普通信息");
console.warn("这是警告");
console.error("这是错误");

consle.log("拼错了"); // ReferenceError: consle is not defined

拼错的变量名会触发 ReferenceError，因为 JavaScript 找不到叫 consle 的东西。
