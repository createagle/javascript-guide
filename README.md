# JavaScript Complete Guide · Demos

**English** | [简体中文](README.zh-CN.md)

Companion demos for *JavaScript Complete Guide* (5 parts, 40 chapters), deployed on GitHub Pages:

**https://createagle.github.io/javascript-guide/**

Every demo runs online. Chapters about the language use a built-in code runner: edit the code, press **Run** (or Ctrl/⌘ + Enter) and read the console output right below. Chapters about browser APIs are interactive pages.

## Layout

```text
index.html                     # Demo index (by part and chapter), generated by tools/build_index.py
404.html
assets/
  style.css                    # Shared styles: light/dark theme, demo layout, code runner, prefers-reduced-motion
  demo.js                      # On every page: ?theme=light|dark and auto-height inside an iframe
  playground.js                # The code runner: editor, Web Worker / sandboxed iframe, console, tests
chapters/
  01-intro/
    README.md                  # Chapter demo list
    01-script-timing.html      # One demo per standalone page
    exercises/                 # Exercise starter (NN-start) and finished (NN-final) code
  02-values-types/
  ...
tools/
  build_index.py               # Rebuilds index.html from the chapter READMEs
  check_pages.mjs              # Opens pages in Chromium: no errors, runners finish, exercise tests pass
  reading_time.py              # Estimates a chapter's reading time from its Markdown export
.github/workflows/
  pages.yml                    # Deploys to GitHub Pages on every push to main
  sync-main.yml                # Fast-forwards claude/** branches into main, then deploys
```

- Demo URL: `https://createagle.github.io/javascript-guide/chapters/<chapter>/<demo>.html`
- Source URL: `https://github.com/createagle/javascript-guide/blob/main/chapters/<chapter>/<demo>.html`
- Demo pages hold only the demo (English copy, no explanations); the explanations live in the tutorial document.

## The code runner

```html
<div class="playground" data-title="Hello">
  <script type="text/plain" class="code">
    console.log('Hello, JavaScript!');
  </script>
</div>
```

- Code runs in a Web Worker, so it cannot freeze or change the page. Code that runs 3 s without a break (an infinite loop) is stopped; timers are stopped 15 s after the start.
- Code runs in strict mode and may use `await` at the top level.
- `console.log/info/warn/error/table/group/count/time` print like a browser console.
- `data-mode="dom"` runs the code as a module in a sandboxed iframe, with markup from `<template class="html">`.
- An optional `<script type="text/plain" class="tests">` adds checks written with `test(name, fn)` and `assert.equal / deepEqual / ok / throws / rejects / match`. Exercise pages use them.
- Edits are saved in the browser (`localStorage`); **Reset** restores the original code.

## Embedding in an iframe

Every page can be embedded. Inside an iframe the page stops stretching to the frame and posts its natural height to the host page, so the frame can fit its content:

```html
<iframe src="https://createagle.github.io/javascript-guide/chapters/01-intro/02-console.html"
        title="JavaScript demo" loading="lazy" style="width: 100%; height: 480px; border: 0"></iframe>
<script>
  addEventListener('message', (event) => {
    if (event.origin !== 'https://createagle.github.io' || event.data?.type !== 'jsguide:resize') return;
    for (const frame of document.querySelectorAll('iframe')) {
      if (frame.contentWindow === event.source) frame.style.height = event.data.height + 'px';
    }
  });
</script>
```

Add `?theme=light` or `?theme=dark` to the URL to match the host page's theme; otherwise pages follow the system setting.

## Adding a demo

1. Copy an existing demo page, then change its English `<title>` and content.
2. Add a row to the table in the chapter's `README.md` and `README.zh-CN.md`.
3. Run `python3 tools/build_index.py` to regenerate `index.html`.
4. Serve the repository (`python3 -m http.server 8000`) and run `node tools/check_pages.mjs chapters/<chapter>/<demo>.html`.

## Deployment

- `.github/workflows/sync-main.yml`: after a push to a `claude/**` branch, fast-forwards `main` and triggers a deployment.
- `.github/workflows/pages.yml`: deploys to GitHub Pages on a push to `main` (or when triggered by the workflow above).

First-time setup: in **Settings → Pages → Build and deployment → Source**, choose **GitHub Actions**, and make `main` the default branch.
